
# NEXUS AI — AI Response Analysis Engine

## Overview

NEXUS AI is a multi-model AI response analysis platform designed to compare answers generated by different AI systems. It identifies common points, potential contradictions, and unique claims to help users understand differences between AI-generated responses.

## Features

- Submit one question for analysis.
- Collect responses from multiple AI providers.
- Compare agreement and potential contradictions.
- Identify unique claims.
- Generate a structured analysis summary.
- Display results in a responsive web interface.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express
- Configuration: dotenv
- AI integrations: OpenAI, Google Gemini, Anthropic Claude, and Sarvam AI

## Setup and Installation

1. Install Node.js (18 or later).
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Install dependencies:

   ```bash
   npm install
   ```

5. Create a `.env` file in the root directory and add your provider API keys:

   ```env
   PORT=3000
   OPENAI_API_KEY=your_key_here
   GEMINI_API_KEY=your_key_here
   ANTHROPIC_API_KEY=your_key_here
   SARVAM_API_KEY=your_key_here
   ```

6. Verify the model identifiers and API settings against each provider's current documentation.
7. Start the application:

   ```bash
   npm start
   ```

8. Open http://localhost:3000 in your browser.

## Important Note

Agreement between AI models does not prove that a claim is factually correct. NEXUS AI analyzes response consistency; independent evidence verification is a separate capability.
